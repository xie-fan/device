# 产品独立于设备类型，start 时选

真实服务端没有产品实体，代码注释还把 `device_type` 叫「产品类型」，读者很容易以为模拟器里的产品就是设备类型。我们仍把**产品**做成独立概念：它描述设备这一侧的全部属性（对话模式、音频格式、身份字段、行为、拍照等功能），在 start 时和挂靠一起选定；设备类型只能配一个「默认产品」，start 不给产品时用它。

## Considered Options

- **产品就是设备类型**：少一层，但同一款硬件挂在多个类型下时要各抄一份，「产品」与「设备类型」变成同义词。
- **设备类型引用产品（多对一）**：能挡住类型与产品对不上的组合，但同一台设备、同一个类型想换产品测，就得先改配置树。

选 start 时单独选，是为了让同一台设备在同一个类型下能换着产品测；代价是能挂出服务端配置与产品对不上的组合，靠 turn.json 记录产品来追溯。
