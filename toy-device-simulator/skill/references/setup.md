# 安装与本机准备

装好后本 skill 是一个自带程序的目录：程序在 `bin/`，配置、数据、录音都在目录里，用的时候不用进模拟器仓库。**配置树里你自己的环境和音频素材都不入库**，每台机器各自准备，准备好就一直留着用，不要用完就删。

## 1. 安装（每台机器一次，仓库更新后重跑）

前置：

- Go 1.22 及以上（只有安装时编译要用）。
- 音频转码程序（可选）：设备用压缩格式（amr / mp3 / aac）或导入非 wav 素材时需要。`configs/manager.yaml` 里有一项填它的路径，留空则从 PATH 里找；找不到时只支持 pcm / wav。

在模拟器仓库的 `toy-device-simulator/` 目录下：

```text
go run ./cmd/simctl install
```

默认装到 `~/.agents/skills/simctl/`（`--to` 可改），并在 `~/.claude/skills/simctl` 不存在时建一个指向它的目录链接：两处是同一份，配置和数据不分家。装完的目录里有：

- `bin/`：`simctl`、`manager`、`echosrv`（本地回环服务端）。
- `SKILL.md`、`references/`：每次安装都覆盖成仓库里的版本。
- `configs/`：只在没有时放默认的；已有的是你本机的配置，重装不动。
- `data/`、`recordings/`：运行后生成，重装不动。

重装前如果装好的 manager 在跑，先 `simctl down`，不然 `bin/manager` 被占住换不掉。

## 2. 启动

```text
<skill 目录>/bin/simctl up
```

设备册为空时会顺手建一台 `sim_0001`（身份字段取默认产品），之后就能 `run`。

## 3. 本机自己准备的部分（不入库）

**配置树**：编辑本 skill 目录的 `configs/registry.yaml`，加你要测的环境、厂商、设备类型。manager 在跑时也可以用 `/registry` 接口加（见 SKILL.md）。加过的条目留着。

**音频素材**：素材库在本 skill 目录的 `data/assets/`，新装时是空的。从调试台素材库（manager 起来后浏览器打开它的地址）或 `POST /assets` 导入，**每条都打内容标签**（`对话`、`联网`、`故事`、`识图` 等），名字写清楚说的是什么。来源不限：录音、语音合成都行。素材前后各留约 0.6 秒、1.2 秒静音，整条 2.5 秒以上，太短服务端可能拿不到识别结果。

测拍照识别还要：

- 一条问图的话，打 `识图` 标签，例如「请看一下这张图片，上面写的是什么？」。
- 一张白底大字的 jpg 图片，字选猜不中的词（例如「紫色的大象」），识图回复才能逐字核对。用任意画图或图片生成手段做都行。

在 Windows 命令行里传中文字段（素材名、图片上的字）容易被转码弄坏：先写进 UTF-8 文件，再从文件读进请求。

## 4. 自检

```text
<skill 目录>/bin/simctl context
```

`alive=true`、`devices` 至少一台、`registry` 里有你要的环境、`audio_tags` 有你要的标签，就可以开始。不连真实服务端时，起 `bin/echosrv` 当本地回环服务端，用配置树里的「本地 / demo / A3」验证链路。
